# 🏥 Axon Healthcare Analytics

## 📌 Project Overview
Axon Healthcare Analytics is an end-to-end Data Analytics project focused on analyzing healthcare data and monitoring key performance indicators (KPIs).

This project uses MySQL, MS Excel, Tableau, and Power BI to analyze patient records, doctors, hospital visits, diagnoses, laboratory tests, and financial performance.

## 🎯 Project Objectives
- Centralize healthcare data for better analysis.
- Monitor important healthcare KPIs.
- Analyze patient visits and clinical patterns.
- Track revenue and treatment costs.
- Build interactive dashboards for data-driven decision-making.

## 🛠️ Tools & Technologies
- **MySQL:** Data querying, filtering, aggregation, and analysis.
- **MS Excel:** Data preparation, cleaning, calculations, and dashboard development.
- **Tableau:** Interactive data visualization.
- **Power BI:** KPI cards, interactive reports, and dashboards.

## 📊 Key Performance Indicators (KPIs)
- Total Patients
- Total Doctors
- Total Visits
- Average Patient Age
- Total Lab Tests
- Total Revenue
- Average Treatment Cost
- Average Patients per Doctor

## 📈 Project Dashboards
This project includes interactive dashboards developed using:

1. MS Excel Dashboard
2. Tableau Dashboard
3. Power BI Dashboard

## 💡 Key Learnings
- Healthcare data analysis and interpretation.
- Data cleaning and preparation.
- SQL querying and aggregation.
- KPI monitoring and visualization.
- Interactive dashboard development.

## 🚀 Conclusion
This project transforms healthcare data into meaningful insights through interactive dashboards. It provides a consolidated view of patient activity, clinical indicators, and financial performance, demonstrating an end-to-end data analytics workflow.
